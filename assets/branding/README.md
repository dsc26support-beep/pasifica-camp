# Pasifika Campus — Branding Assets

Approved **Pasifika Campus** brand artwork and the assets derived from it.

## Approved source artwork (`source/`)

The official logos, exactly as supplied — **use as provided; do not distort,
stretch, recolour, or redesign**.

| File | What it is |
|------|-----------|
| `source/logo-option-1.png` | **Logo Option 1** — P-monogram (palm, sun, ocean waves, Pacific pattern) + PASIFIKA CAMPUS wordmark, gold on black |
| `source/logo-options-1-and-2.png` | Options 1 (P-monogram) & 2 (horizontal emblem + tagline) |
| `source/brand-board.png` | Full brand board: logos, colour specs, UI direction, typography |

## App assets (derived from Logo Option 1)

Generated by `scripts/gen-branding.js` (crops the P-monogram, keys the black
background to transparent, composites onto brand charcoal `#0D0D0D`). Re-run:
`node scripts/gen-branding.js`.

| File | Size | Used by |
|------|------|---------|
| `app-icon.png` | 1024² | `app.json` › `icon` (the P-monogram — strongest brand element) |
| `adaptive-icon.png` | 1024² | `app.json` › Android adaptive foreground (transparent, safe-zone) |
| `splash.png` | 1284×2778 | `app.json` › splash (full logo on charcoal) |
| `pasifika-campus-logo-primary.png` | 1024² | in-app full logo (`LogoFull`) |
| `logo-mark.png` | ≤512² | in-app P-monogram (`LogoMark`, `LogoHorizontal`) |
| `brand-colours.json` | — | colour tokens (mirrored in `constants/colors.ts`) |

The in-app `components/ui/Logo.tsx` renders these PNGs directly, so the real
brand mark appears throughout the app.
