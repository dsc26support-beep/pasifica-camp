## Affiliate marketing funnel engine

This project includes a lightweight, highly automated affiliate marketing
campaign engine — a campaign-centric system that takes an affiliate offer and
automatically generates the landing page, lead magnet, email sequence,
content, social posts, tracking, and analytics around it.

The full build scope is tracked in
[`docs/affiliate-funnel-requirements.md`](docs/affiliate-funnel-requirements.md) —
start there before adding new work.
